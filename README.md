# ContestOps AI Web

Vue3 CDN + SFC + UnoCSS demo console for ContestOps AI.

Run locally:

```powershell
node scripts\static-server.mjs 4177
```

Open:

```text
http://127.0.0.1:4177/
```

Public demo:

```text
https://jechaviz.github.io/contestops_ai_web/
```

The first screen is the product workspace, not a landing page.
